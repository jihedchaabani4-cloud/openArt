📋 محطات خط الإنتاج (Stages Breakdown)

1 codebase-design

Feature Analyst

يفحص الـ Feature بدقة: يفرز الملفات السائبة (Loose files)، الـ hooks المخلطة مع الـ UI، ويفحص الـ Public API (`index.js`).

المخرجات: قائمة بالـ Friction Points والـ Dependencies الخارجية.
2 improve-architecture

Architecture Planner

يصمم المعمارية المستهدفة للـ Slice بناءً على FSD النقي: يحدد مكان الـ `model/` (الستورز والهوكس)، و `api/` (الريكوستات)، و `ui/` (الواجهات فقط).

المخرجات: Deep Module Interface & Target File Tree.
3 grilling + council

Critic & Grilling Agent

يمتحن المخطط بصرامة: هل فيه Over-engineering؟ هل فما خطر كسر للتستات أو الـ UI؟ هل الـ Refactor يحترم قاعدة YAGNI والـ Deletion test؟

المخرجات: تمحيص المخطط وحذف أي تعقيد زايد قبل الكود.
4 to-tickets

Ticket Decomposer

يقسم الخطة إلى تذاكر رأسية ذرية (Atomic Tracer-Bullet Tickets): كل تذكرة عندها Scope محدد، Blocking Dependencies، وشروط نجاح حاسمة.

المخرجات: تذاكر مرتبة ومنظمة حسب الأسبقية.
5 wayfinder

Ticket Reviewer

يتأكد أن التذاكر مصنفة صح: الـ Mechanical moves تسير بـ Expand-Contract، ولا توجد تذكرة تبدأ قبل اكتمال متطلباتها السابقة.

المخرجات: مصادقة نهائية على خطة التنفيذ وتجنب الـ Blast Radius.
6 implement + tdd

Execution Agent

ينفذ التذاكر تذكرة بتذكرة: نقل الملفات، ضبط الـ imports، تحديث التستات، والتأكد الفوري من أن كل خطوة تنتهي بنتيجة خضراء 100%.

المخرجات: كود معدل ومنقول بدقة بدون أي تراجع وظيفي.
