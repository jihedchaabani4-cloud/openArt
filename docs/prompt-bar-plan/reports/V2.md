Perform a comprehensive audit of all consumers of the legacy global stores (`usePromptStore`, `useCharacterStore`, `useElementStore`). - Inspection of `useMediaActions.js`, `MediaGridItem.jsx`, `elements/edit/[workflowId]/page.js`, and drag auto-scroll hooks.
- Verification of dual-write sites in `handleReuseSettings` and `handleAnimate`.

## 4. Answers to Questions

### Q1: List every import and every field or action each consumer reads or writes
- **`useElementStore`**: It is not an independent store; it is a direct re-export / alias of `useCharacterStore` (`useCharacterStore.js:241`).
  - `elements/edit/[workflowId]/page.js:20-21`: calls `hydrateElementDraft` and `resetElementStore`.
  - `useMediaActions.js:110-112`: calls `setPrompt` and mutates `features`.
- **`useCharacterStore`**:
  - `characters/new/page.js:124`: calls `setPrompt` on archetype click.
  - `FeatureNode.jsx:8`: calls `openFeatureEditorForLabel`.
  - `SyncFeaturesPlugin.jsx:10-11`: reads `features`, calls `updateFeature`.
  - `TextTagConverterPlugin.jsx:20`: calls `updateFeature`.
- **`usePromptStore`**:
  - Drag consumers: `assets/page.js`, `collection/page.js`, `elements/page.js`, `StudioNavbarLeft.jsx`, `MediaGridItem.jsx`, `useStudioItemDrag.js`, `useDragAutoScroll.js`. All strictly read or write `isDraggingGalleryItem` and `draggedItem`.
  - Prompt Bar duplicate consumers: `useMediaActions.js` and `elements/edit/[workflowId]/page.js`. Read/write `prompt`, `modelId`, `generationMode`, `ratio`, `quality`, `videoResolution`, `duration`, `motion`, `count`, `referenceImages`.

### Q3: Dual-write sites
Exact quote from `src/features/workflows/model/useMediaActions.js:149-181`:
```javascript
// 1. Sync with Platform PromptBar store (if active on screen)
const activeBarStore = getActivePromptBarStore();
if (activeBarStore) {
  const barState = activeBarStore.getState();
  if (effectivePrompt && barState.setPrompt) {
    barState.setPrompt(effectivePrompt);
  }
  if (modelName && barState.selectModel) {
    barState.selectModel(modelName);
  }
  if (ratioVal && barState.setParameter) {
    barState.setParameter("ratio", ratioVal);
    barState.setParameter("aspect_ratio", ratioVal);
  }
  if (barState.setActiveMode) {
    barState.setActiveMode(isVideo ? "video" : "image");
  }
}

// 2. Sync with Legacy / Global Prompt store
const promptStore = usePromptStore.getState();
promptStore.setGenerationMode(isVideo ? "keyframe" : "image");
if (effectivePrompt) promptStore.setPrompt(effectivePrompt);
if (modelName) promptStore.setModelId(modelName);
if (ratioVal) promptStore.setRatio(ratioVal);
if (refs.length) promptStore.setReferenceImages(refs);

if (promptStore.setQuality) promptStore.setQuality(qualityVal || "2K");
if (promptStore.setVideoResolution) promptStore.setVideoResolution(videoResVal || "1080p");
if (promptStore.setDuration) promptStore.setDuration(durationVal || "5s");
if (promptStore.setMotion) promptStore.setMotion(motionVal ?? 50);
if (promptStore.setCount) promptStore.setCount(countVal);
```

### Q4: Order proposal for migration in P5
1. `src/app/cinema-studio/[projectId]/elements/edit/[workflowId]/page.js`: Migrate initial preset logic to route/local state.
2. `src/features/workflows/model/useMediaActions.js`: Replace dual-write and fallback blocks in `handleReuseSettings`, `handleAnimate`, and `handleUseAsReference` with unified calls to `promptBarService`.
3. Drag-and-drop state: Keep in `usePromptStore` per PB-D-17 to avoid touching gallery interactions.

## 5. Verdict
**CONFIRMED**: Dual-write exists in `useMediaActions.js`. Generation parameters in `usePromptStore` duplicate the instance store and are only used by `useMediaActions.js` and `elements/edit/.../page.js`. Drag state is independent and correctly classified as KEEP.

## 6. Risks
- Removing `usePromptStore` writes from `useMediaActions.js` prematurely before `promptBarService` is fully connected could break "Reuse settings" if the active bar store is not mounted.
- `useElementStore` being an alias to `useCharacterStore` means mutations on element forms share state with character forms if both were ever mounted concurrently.
