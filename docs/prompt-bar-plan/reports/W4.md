# Task W4 Report: Proof that Model and Mode are Optional (PB-D-13)

## Overview
Demonstrated and verified that the Prompt Bar platform architecture supports templates with no model selector and no modes (`features: { models: false, modes: false }`), paving the way for future specialized bars (such as Character bar) without introducing domain leakage into Core.

## Classification of Touched Files
- **CREATED**:
  - `src/features/prompt-bar/__tests__/fixtures/promptOnly.template.js`
  - `src/features/prompt-bar/__tests__/promptOnlyTemplate.test.jsx`
- **EXTENDED**:
  - `src/features/prompt-bar/core/templateContract.js` (preserve `parameters` and `mediaLimit` on frozen template)
  - `src/features/prompt-bar/core/initialization.js` (initialize static parameter defaults when `features.models === false`)
  - `src/features/prompt-bar/core/media.js` (allow `getActiveSlots` and `getSlotMaxRefs` to resolve template slots and quotas without requiring model)
  - `src/features/prompt-bar/core/serialization.js` (make `model` optional in payload, collect references across declared parameter definitions)
  - `src/features/prompt-bar/store/commands/attachMedia.js` (fallback to `template.parameters` definition when `currentModel` is null)
  - `src/features/prompt-bar/store/createPromptBarStore.js` (initialize `parameterValues` from `template.parameters` when models are absent; fallback to template parameters in `serialize` and `reset`)
  - `src/features/prompt-bar/platform/PromptBarPlatform.jsx` (forward `hasModels` flag based on template features/layout)
  - `src/features/prompt-bar/platform/hooks/usePromptBarGenerate.js` (support `hasModels` toggle so lacking a model does not block generation)

   - Slot mapping for `front`, `side`, `closeup`.
   - `mediaLimit: 3`.

   - `(d) switchMode and selectModel are not required to exist and are not called`: VERIFIED.
   - `(e) clicking Generate in mounted bar invokes onGenerate with serialized payload omitting model`: VERIFIED.
