# Task W2 Report: Route Policy & Route Watcher (PB-D-14)

## Overview
Implemented pure pattern matching for route-based persistence (`store/routePolicy.js`) and a route watcher hook (`usePromptBarRouteWatcher`) that automatically resets and purges persistence snapshots for Prompt Bar instances when the user navigates away from allowed routes.

## Deliverables
1. **Pure Route Policy (`store/routePolicy.js`)**:
   - `normalizePathSegments(rawPath)`: Strips query strings, hashes, leading/trailing slashes.
   - `matchRoute(pattern, pathname)`: Matches exact paths, `:param` single segment parameters, and `/*` trailing recursive wildcards.
   - `isPathAllowed(pathname, patterns)`: Evaluates path against allowed patterns; defaults to "always allowed" if patterns are omitted or empty.
   - Tested in `src/features/prompt-bar/__tests__/routePolicy.test.js` (14 tests passed).

2. **Registry Meta Support (`store/registry.js`)**:
   - `getOrCreate(identity, factory, meta)` and `markMounted(identity, meta)`: Stores `meta` on the entry (e.g., `persistRoutes`, `storage`, `canonicalKey`, `legacyKey`).
   - `setMeta(identity, meta)` and `getMeta(identity)` helpers.
   - `list()` exposes `meta` per instance entry.

3. **Template Route Declaration**:
   - `src/features/prompt-bar/templates/generatedMedia.template.js`: Declares `persistRoutes`:
     - `"/cinema-studio/:projectId/assets"`
     - `"/cinema-studio/:projectId/collection/*"`
     - `"/cinema-studio/:projectId/collections/*"`
     - `"/cinema-studio/new"`
     - `"/cinema-studio/test/prompt-bar-compare"`

4. **Route Watcher Hook (`store/usePromptBarRouteWatcher.js`)**:
   - **Contract**: *Watches pathname navigation and resets any non-submitting Prompt Bar instance whose template persistRoutes disallow the current path.*
   - Inspects `reg.list()` on pathname change.
   - Skips instances without `persistRoutes` (unrestricted persistence).
   - Skips instances with active submits in flight (`reg.isSubmitting(identity)`).
   - Resets state (`reg.reset(identity)`) and removes storage snapshot (`removeSaved(storage, key)`).
   - Tested in `src/features/prompt-bar/__tests__/usePromptBarRouteWatcher.test.jsx` (5 tests passed).

5. **Single Layout Mount**:
   - Mounted once in `src/app/cinema-studio/[projectId]/layout.js:29` inside `StudioLayout`.
