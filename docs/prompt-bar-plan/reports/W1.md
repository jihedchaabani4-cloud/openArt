# Task W1 Report: GeneratedPromptBar Wrapper & Page Migrations

## Overview
Replaced repeated boilerplate (`type={generatedMediaType}`, `featureConfig={generatedMediaConfig}`, `persistKey`, `projectId`) across all consuming pages with a single ready-to-use component: `<GeneratedPromptBar />`.

## Deliverables
1. **Wrapper Component**:
   - `src/features/prompt-bar/templates/GeneratedPromptBar.jsx`:
     - Renders `PromptBarPlatform` pre-bound to `generatedMediaTemplate`.
     - Supports `instanceId` (default `"default"`), `persistKey` (default `"studio-prompt-bar"`), `projectId`, and forwards all standard platform props (`models`, `onGenerate`, `isGenerating`, `hideBackground`, etc.).
   - Exported `GeneratedPromptBar` and `generatedMediaTemplate` from `src/features/prompt-bar/index.platform.js`.

2. **Prop & Store Parity**:
   - `src/features/prompt-bar/platform/PromptBarPlatform.jsx`: Accepts optional `projectId` prop and forwards to `PromptBarStoreProvider`.
   - `src/features/prompt-bar/store/PromptBarStoreContext.js`: Accepts explicit `projectId`, falling back to route resolution if omitted.

3. **Verification Test**:
   - `src/features/prompt-bar/__tests__/GeneratedPromptBar.test.jsx`:
     - Verifies reference slot rendering in image mode.
     - Verifies golden payload generation with start/end frames model.
     - Verifies extra props passthrough (`className`, `isGenerating`).
     - Verifies multi-instance store isolation (`instanceId="bar-alpha"` vs `"bar-beta"`).

4. **Migrated Consumers**:
   - `src/app/cinema-studio/[projectId]/assets/page.js`: bare platform replaced with `<GeneratedPromptBar projectId={projectId} ... />`.
   - `src/app/cinema-studio/[projectId]/collection/[collectionId]/page.js`: bare platform replaced with `<GeneratedPromptBar projectId={projectId} ... />`.
   - `src/widgets/StudioLayout/NewProjectView/NewProjectView.jsx`: bare platform replaced with `<GeneratedPromptBar projectId={projectId} ... />`.
   - `src/app/cinema-studio/test/prompt-bar-compare/page.jsx`: bare platform replaced with `<GeneratedPromptBar instanceId={instanceLabel} ... />`.

5. **Residual Search**:
   - `rg -n "type=\{generatedMediaType\}" src/` confirms that no application pages use the legacy bare invocation anymore (only unit tests exercising backward compatibility).
